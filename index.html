Privacy & GDPR Notice

RootDonate stores conversation memory locally in your browser (localStorage) and optionally in Firebase so you can resume via URL.

Data processed:
• Chat messages and memory facts
• Optional session ID in the URL
• Microphone audio (only while listening is active; processed by the browser’s Web Speech API)

You can delete all data at any time using the “Decline / Clear” button or by clearing site data in your browser.

Speech recognition is provided by your browser (Chrome usually sends audio to Google). We do not store raw audio.
